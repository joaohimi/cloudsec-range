# Definition of Done

A feature is not done because the UI exists. It is done when the behavior is implemented, tested, documented and protected.

## Product feature

- Acceptance criteria written and traceable to a requirement.
- Server-side authorization implemented.
- Input validation and error behavior defined.
- Unit/integration tests included.
- Audit events considered.
- Accessibility and responsive behavior checked.
- Documentation updated.

## Learning competency

- Theory and terminology complete.
- Official references attached and version-checked.
- Guided and independent practice available.
- Troubleshooting exercise available.
- Internship mapping exists.
- Rubric and objective verification defined.
- Evidence requirements defined.

## Internship scenario

- Fictional company context and assets described.
- Initial state reproducible.
- Scope and permissions explicit.
- Acceptance criteria measurable.
- Safe execution boundary defined.
- Remediation validated.
- Deliverables and reviewer rubric defined.

## Lab

- Image/version allowlisted.
- Network and filesystem isolation tested.
- Resource/time limits enforced.
- Reset and cleanup are idempotent.
- Cleanup failure is detectable.
- No host or personal credentials exposed.
- Test fixtures and expected results documented.
